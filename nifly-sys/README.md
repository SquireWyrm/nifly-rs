# nifly-sys

Raw [cxx](https://cxx.rs) bindings to [nifly](https://github.com/ousnius/nifly), the C++ library
for NIF files. nifly's sources are vendored and built with the crate, which needs a C++17
compiler.

Use the [`nifly`](https://crates.io/crates/nifly) crate for a safe API.
